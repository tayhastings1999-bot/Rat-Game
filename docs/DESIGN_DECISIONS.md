# Design decisions

A running log of decisions about Scurry's direction, with the reasons for them. Update it in every PR that changes direction.

| Date | Decision | Rationale |
|---|---|---|
| 2026-10-12 | **Target: Steam release in 6–12 months.** | Taylor's goal. It sets the priorities: a cohesive core loop first, then a vertical slice, content, polish, and Steam work (desktop wrapper, Steamworks, store page) in parallel near the end. |
| 2026-10-12 | **Feel: close to Gauntlet: Dark Legacy.** | Taylor's reference. It fits what the README rebuild already planned (fixed camera, nests that spawn enemies, health drain plus food, keys and locks, turbo). New systems should push toward that arcade dungeon-crawler feel rather than the old roguelite layer. |
| 2026-10-12 | **No trademarked names.** Shop items, power-ups and modes use Scurry's own names (Splitclaw, Mirror Shell, Rot Vial, Second Tail…). | We borrow the shape of GDL's systems, not its names, to stay safe for a commercial release. |
| 2026-10-12 | **Three save slots ("burrows"), versioned.** Old single saves move into slot 1; the old keys are kept. | Per-player progress, couch households, and safe save migrations as the format changes. Keeping the old keys means rolling back to an older build loses nothing. |
| 2026-10-12 | **The Nest is the hub between runs** (a menu screen for now). Gold is banked on death and spent there. | It closes the loop (hub → run → hub) and gives gold a purpose. A walkable hub is a later upgrade. |
| 2026-10-12 | **GDL-style shop with three kinds of stock:** permanent stat upgrades (Strength, Armor, Speed, Magic, HP, gold pickup), supplies for the next run (Rot Vials, keys, cheese, Second Tail), and flasks (bottled power-ups). | It mirrors GDL's stat upgrades, potions, keys and timed items while reusing Scurry's existing systems (Rot Vials, keys/locks, power-ups) instead of duplicating them. |
| 2026-10-12 | **Flasks are held items used with a button** (V to use, B to cycle; touch Flask/Swap; the gamepad's d-pad), with a HUD slot and timer. | Taylor's call, matching GDL. Timing a power-up is a player decision, not an automatic trigger. |
| 2026-10-12 | **Difficulty: Casual / Normal / Insane**, picked in the Nest and saved per slot. Gold ×0.75 / ×1 / ×1.75. All values are in `TUNE.difficulty`. | Wider audience on Casual, a reason to replay on Insane; the higher gold payout rewards the risk (Taylor confirmed). |
| 2026-10-12 | **Local co-op for 2–4 players** on a shared screen (keyboard split plus gamepads). The camera frames everyone. Enemies chase the nearest rat. Each rat has its own HP, class, turbo and flasks. Gold, keys and XP are shared. A downed rat is revived by standing next to it. | GDL is a 4-player co-op game at heart. Local first, because Steam Remote Play Together turns local co-op into online play without netcode. |
| 2026-10-12 | **Friendly fire off.** | Taylor's call. Keeps co-op chaotic but friendly. |
| 2026-10-12 | **Player-count scaling** (`TUNE.coop.perPlayer`): each extra rat adds enemy HP, damage, spawn rate, elite odds, boss HP and nest children. It stacks with difficulty. | Gauntlet-style: more players must still be challenged, or co-op gets trivial. |
| 2026-10-12 | **Gamepad first-class in single player** (pad 1 drives player 1 next to keyboard and mouse; Start pauses). | Needed for Steam Deck and couch play, and it's what Steam players expect for this genre. |
| 2026-10-12 | **Player colours in co-op: red, blue, yellow, green** (ground ring plus HUD card), GDL-style. | Readability: with 4 rats in a crowd you need to find yourself at a glance. |
| 2026-10-12 | **The announcer names the player in co-op and calls downs and revives.** | Arcade-style callouts are part of the GDL feel, and in co-op you need to know who is in trouble. |
| 2026-10-12 | **Dead code removed only when nothing references it.** Overlapping systems are flagged for a decision rather than cut (see the audit in the polish-pass PR). | Keep reviews safe. Big cuts are Taylor's call. |
| 2026-10-12 | **Shop prices are multiples of average gold per level** (`TUNE.shop.goldPerLevel`, currently an estimate of 250 to be measured): supplies ~0.15–0.25×, flasks ~0.7–1.2×, Second Tail 1.5×, permanent stats a flat 2× (GDL's flat +10-stat price). | From the research (GDL price ladder). One knob rebalances the whole shop when gold income changes, and Insane's higher payout speeds up purchases without breaking the curve. |
| 2026-10-12 | **Packed supplies and flasks sell back at 75%** (`TUNE.shop.sellBack`). Permanent upgrades can't be sold. | GDL sells back at about 75%. Experimenting is cheap, and an unused purchase isn't a total loss. |
| 2026-10-12 | **Flasks toggle:** V uncorks; V again corks and saves the remaining time; V again resumes. | GDL lets you toggle held power-ups to save their duration. Charge-based items wait until there are charge-style power-ups (none exist yet). |
| 2026-10-12 | **Co-op continues:** a downed rat has a 15s window for a teammate revive (limited per level by difficulty). After that the party spends a shared **cheese token** (Scurry's coin continue). With no tokens left, the rat sits out until the next level. Casual: unlimited tokens and revives. Normal: 3 tokens, 2 revives per rat per level. Insane: 2 tokens, no teammate revives. | Research: GDL's coin continues, adapted for a home game. Gives co-op stakes that scale with difficulty. |
| 2026-10-12 | **Party scaling raises enemy HP and spawn pressure, not damage** (`perPlayer.dmg = 0`). | Uneven damage scaling is the top complaint in reviews of comparable co-op games (Hammerwatch II). Test each player count separately. |
| 2026-10-12 | **All saves are JSON blobs behind a storage layer** (`src/core/storage.js`, `setStorageBackend`). | A later Electron build can write one JSON file per slot into AppData for Steam Auto-Cloud without touching game code. |
| 2026-10-12 | **Art direction: "Gauntlet in a can of spray paint"** (art bible v1). Readable top-down horde chaos, hard toon light, black outlines, saturated actors on a muted world, Y2K arcade chrome UI. | Taylor approved the bible. It fixes the critique of the current build: an unreadable hero, a cramped camera, muddy post-processing and no colour hierarchy. |
| 2026-10-12 | **One 15-colour palette** (`src/render/palette.js`, mirrored as CSS variables). Player hues (red, blue, yellow, green) are reserved for players and UI. Class `rc` colours are menu accents only. | Colour value is how things read at thumbnail size. Players are identified by colour, classes by silhouette. |
| 2026-10-12 | **Fixed high 3/4 camera:** FOV 35, ~62° pitch, 22 world units across (wheel 18–30), yaw locked. Co-op frames every standing rat with 3 units of padding. | Gauntlet shows the room, not just the hero. |
| 2026-10-12 | **Quieter post:** grain 0.01, vignette 0.3, dither 0.35, 360-line internal resolution (min 270), PS1 snap ~480×270, plus a depth-edge outline pass. Values are in `TUNE.art`. | "Sleek, not muddy". The PS1 flavour stays as a light touch. |
| 2026-10-12 | **Toon shading (3-step ramp) and inverted-hull outlines** on rats, mobs and bosses. In co-op the hero hull gets an outer player-colour layer. Mob hulls switch off above 120 on-screen mobs (perf guard). | Hard light plus outlines give clean silhouettes in a horde. The guard keeps the 200-mob cap affordable. |
| 2026-10-12 | **Player rings:** an unlit pulsing ring in the player's colour under every rat (solo too). Blob shadows are Void at 45%. | You find yourself instantly, Gauntlet-style. |
| 2026-10-12 | **No player hues on enemies** (review of #4): every enemy body is graded at load to one desaturated dark tone (`TUNE.art.enemyTone`, 20% darker). Glows become Enemy Purple (cool) or Hazard Orange (warm). Telegraphs, state tints and attack-warning discs moved off red/blue/yellow/green onto orange/purple/lime. | Red reads as "P1", so the horde has to sit in a different colour band. |
| 2026-10-12 | **Hero identity:** the class-coloured turbo ground ring (the "red disc") is removed. The player ring is thicker (0.16), fully saturated, drawn over enemies (no depth test, renderOrder 20). A floating shape glyph marks each player: P1 ▼ triangle, P2 ● circle, P3 ■ square, P4 ◆ diamond. Hero materials get a fresnel rim in the player colour, and heroes are 1.25× scale. | Pass bar: P1 and P2 found in under a second in a 320px horde thumbnail. Shapes also help colour-blind players. |
| 2026-10-12 | **P11 floors:** floor tiles are Concrete (city) or dark teal-grey `#2B3A3C` (sewer), with the zone's floor colour as a 12% tint. Tile contrast ≤12%, crack/decal contrast halved, asphalt in the Slate band. No yellow-green sewer. | The floor should never compete with actors. |
| 2026-10-12 | **HUD:** Pirata One removed (and its package dropped). Bungee for names and callouts, Silkscreen for numbers. One system of four chrome panels along the top (per player: name, HP, gold, keys, vials, HP bar, combo bar; empty slots show PRESS START / cheese tokens). The empty top XP bar and the DAMAGE/KILLS/COMBO cluster are gone: combo is in the player panel, and level/XP is a small tag on the objective strip. The bottom plate keeps only turbo and ability slots. The old co-op cards (and the overlapping Cheese Tokens card) are replaced by the panels. | GDL/arcade read: everything about a player is in one place at the top, in that player's colour. |
| 2026-10-12 | **Announcer and minimap:** callouts use Bungee with a chrome gradient fill, a black outline and a one-line subtitle (ellipsised). The minimap sits in a chrome bevel frame. | Matches the chrome panel system. |
| 2026-10-12 | **Combo folded into turbo.** The separate combo meter and its UI are gone (it also never broke on a hit: `comboBreak` was imported but never called). A hit streak (hits within 2.5 s, kills count 2, a perfect dodge 4) adds +2% turbo gain per hit past 5, capped at +20%, and resets when you take a hit. Values are in `TUNE.turbo.streak`. The panel's second bar is turbo and pulses while the bonus is active. | One meter to read. Skilful aggression is rewarded without a second resource. |
| 2026-10-12 | **Balance principle: "strong, never safe."** Power must visibly grow (levels, shop, flasks, turbo) and challenge must keep up, so overcoming it always feels earned. Concretely (`TUNE.balance`): stats soft-cap past 10 (diminishing, asymptote 18). Armor alone stops at ×0.4 damage taken, and the full stack (Armor × Iron Hide × buffs) at ×0.25. Stacked player damage multipliers soft-cap past ×2.5. Enemies follow the rat's actual power (HP × offense-gain^0.35, damage × effective-HP-gain^0.35), measured from the run's own start, so shop upgrades keep their value. | The balance probe showed defense running away: mawling hits-to-die went 17 → 80 at level 99 (233 with Iron Hide), i.e. nothing could threaten a high-level rat. After the change it's 17 → 22 (35 with Iron Hide). Enemies hit relatively harder as you grow, but flasks still roughly double survivability. `npm run balance` re-measures. |
| 2026-10-12 | **Removed:** trial mode (`G.mode` was always 'survival'; 3 dead `trial` checks), every level-up-screen handler in tests (the `levelup` state is never set any more), `.panel.breakthrough` / `.slot.evo` CSS (no code uses them), `meta.startAt` / `G.mode` writes in baseline/pace scripts (cut systems), a smoke step that zeroed a non-existent `st.xp`, and the turbo ground ring. | Dead paths hide real failures and mislead future changes. |
| 2026-10-12 | **Insane: "brutal but accomplishable."** Enemies hit ×1.6 and attack ×1.25 faster (cooldowns only; wind-up telegraphs are never shortened), move ×1.08, HP ×1.3, elites ×2, spawns ×1.3. Food heals ×0.6, street power-ups are halved, you start with 1 fewer Rot Vial, there's 1 cheese token and no teammate revives. Bosses: HP ×1.15, and their damage is ×0.7 on top of the ×1.6, because bot runs showed the first boss was an unbeatable wall. Rules, telegraphs and hazards are the same as Normal. `npm run insane` checks it. | Mistakes are punished hard and resources are tight, but every hit is readable and avoidable. Bot check (4 trials, first zone, maxed shop): Normal 3/4 expert, 2/4 average, 2/4 novice clears. Insane 1/4 expert, 0/4 average, 0/4 novice. No unavoidable-damage anomalies were logged. |
| 2026-10-12 | **QA follow-ups (Rat 7 report).** Packed cheese is checked on every HP loss: hits, the constant drain and the Reaper's drain. The pre-slot save migrates only once (`scurry.migrated` flag), so deleting every slot doesn't bring it back. During the co-op end-of-frame revive and leash pass, `coop.active = -1`, so writes to the lead rat go to its stored copy and aren't lost when P1 is swapped back in. | The shop promises cheese "eaten by itself below 25% HP", and drain is the main HP loss. Deleted saves must stay deleted. Co-op rules have to hold for the lead rat too. |
| 2026-10-12 | **A worn-off flask isn't "held".** Once a flask's timer runs out, it drops out of the held list (no empty HUD slot, B doesn't cycle onto it), and V clears it. The co-op revive limit resets per level for the lead rat too (boot check added). | Follow-ups from the QA report: F5 and F3 as seen on #3. |
| 2026-10-12 | **Co-op power-following is per rat.** `pow0`, `powHp` and `powDmg` are per-rat run fields, and each extra rat records its own baseline in `coopStart`. A rat takes enemy damage scaled by its own power gain. Enemy HP follows the rat whose pass spawns them. | QA F4: everyone was measured against P1's start, and the last rat to level set the value for the whole party. |
| 2026-10-12 | **The roster is four classes (Taylor's decision):** Sewer Rat (tank), Sewer Slinger, Rat Warlock and Sewer Sneak. Gutter Brawler, Plaguebearer and Roof Rat are cut, along with their stats, primaries (Claw Rake, Blight Lob, Needle Darts), specials (Leap Slam, Plague Nova, Updraft), signatures (Grab & Hurl and its held-mob code, Blight Burst, Dive Bomb and its landing), turbo blasts and flourishes, rig gear, icons, the bot's ranged list, tests and README rows. **Mechanics reused:** the Brawler's heal-on-hit and Bloodlust live on with the Sewer Rat. Bloodlust (speed per kill) now also reaches the Sneak, because `meleePrim` is read from `PRIM[..].melee`; before, only Rake and Gnash counted, which was a bug. Elder Moss (story NPC) is now drawn from the Sewer Rat rig, not the Plaguebearer's. **Saves v3:** a slot remembers its picked class (`meta.cls`) and co-op seats (`meta.coopCls`). Any cut class maps to its heir: Brawler → Sewer Rat, Plaguebearer → Warlock, Roof Rat → Slinger. Older per-class fur picks merge onto the heir, and the heir's own pick wins. `startRun` maps old ids the same way. Skins are still global. | Taylor's decision. Each heir is the nearest role, so a returning player keeps the playstyle they picked. |
| 2026-10-12 | **Four-class balance, "strong, never safe".** Sling Stone scales ½ Strength + ½ Magic (`PRIM.mag`), and Hex Bolt scales with Magic. Enemy power-following now uses the primary's real multiplier (`primScale()`), not raw Strength. Stats: Sewer Rat HP 215→195, ARM 9→8, life-steal 0.6→0.5. Slinger HP 120→115, STR 5→4, ARM 4→3, MAG 4→7, stone 10→11. Warlock HP 100→110, hex 11→13. Sneak unchanged. Probe (`scripts/classes.mjs`, max shop, lv 99, seconds to kill a mawling / hits to die): Rat 0.47 / 30.3, Slinger 0.64→0.56 / 21.6→19.9, Warlock 1.09→0.73 / 15.5→16.2, Sneak 0.35 / 14.8. | The Slinger's stones only scaled with Strength, while enemies followed Strength and Magic, so it fell behind late. The Warlock's primary ran on STR 3 and was the weakest late. The Sewer Rat was the one class that was close to safe. |
| 2026-10-12 | **Boss intros are a ~2.5 s bark only (Taylor's decision, relayed).** `bossIntro` announces the name, title and taunt (`TUNE.announcer.bossSecs`) plus the boss sting. The intro card and its 0.7 s slow-mo are removed. No boss intro sets slow-mo, changes `G.state` or opens a story scene (story scenes run at run start, district, cages, Scab and boss death, never at an intro). The smoke test asserts the intro is a bark, the state stays `play`, slow-mo is 0 and there is no card. | Taylor's decision: the fight starts at once. |
| 2026-10-12 | **Co-op exits (Taylor approved).** The manhole is lead-only, like the road, ladder and drain. The lead is the first rat still standing (`isLead()` in coop.js). A non-lead pressing E gets "P1 leads the way down" and the key isn't used. Linked pipes move only the rat that used it. In co-op there is no fade and no 'trans' freeze: the rat ducks in for 0.24 s (locked and invulnerable) and comes out at the pipe's exit while everyone else keeps playing. If the exit is past the leash range from the lead, the whole party goes through together, so the leash never snaps the rat back. Solo pipes keep the fade. Boot check covers both. |
| 2026-10-12 | **Class unlock hook (for future secret rats, not built yet).** Classes stay data-driven: a `CLASSES` entry can carry `unlock: { req: meta => bool, hint }` and `secret: true`. `classOpen`, `pickerClasses` and `openClasses` gate the picker, number keys and co-op cycling. Locked non-secret rats show a disabled "Locked" card with the hint. Secret rats stay hidden until unlocked. `liveClass` falls back to the Sewer Rat for locked or unknown ids, and saves keep unknown ids instead of erasing them. Unlocks stick through `meta['c_'+id]`. The roster is still the final four. A boot check covers the hook. |
| 2026-10-12 | **Treasure rooms (Taylor approved).** This is a new secret zone, `treasure`: a 25 s timed room with about 70 gold piles (3 coins each) and 2 premium chests. It has no enemies, nests or thieves, and the exit is open from the start. You can get there two ways. Leaving a level by road or ladder sends you there first 12% of the time (`TUNE.treasure.odds`), from zone 2 on and never twice in a row, and then you go on to the next level as normal. Also, about 35% of levels with no fixed secret zone hide a drain to one. That pick is seeded by level, without touching the level's rng stream, so layouts don't change. Bots and tests skip the random detour. Boot check added. |
| 2026-10-12 | **Shootable food and potions (Taylor approved).** Player shots and swings already smashed food (a shot stops at the food, and the line-of-fire flash warns you). Now they also pop Rot Vials lying on the floor: `popVialsAt` sets off a rot burst at the flask at `TUNE.vials.shotMul` (0.75×) damage, a trap you can spring from range. The burst only hits enemies, nests, bosses and the Reaper, never a rat, so co-op friendly fire stays off. Thrown vials share the same `burst()`. Boot check added. |
| 2026-10-12 | **Four-class follow-ups.** The Warlock card colour is now `#3BF2FF`. Default co-op slots were already P1 Sewer Rat, P2 Slinger, P3 Warlock, P4 Sneak (in `META0.coopCls` and `coop.setup.cls`), so they're unchanged. The dead Roof Rat glider code is removed from `makeRat`/`ratExtras`. Story CRs from /workspace/scurry-story/CODE_CHANGE_REQUESTS.md: CR-1 was already fixed on main (Moss is built on the Sewer Rat), and CR-2 to CR-7 are applied (yellow-mask taunt, the new fire timeline, Pip's motive, the Knot line, the Unit 8 crown beat, the chapter-6 crown bark). CR-8 is skipped because it's optional and needs a new level-start hook. The README now has the new fire timeline and four-class wording. Barks gated on cut classes are left as they are. |
| 2026-10-12 | **Drop-in/drop-out co-op (Taylor approved).** Rats can join or leave mid-run. Pressing Start on a gamepad that isn't in the party drops it in. The exception is gamepad 1 in solo play: it's player 1's pad, so Start pauses as before. F6 toggles the second keyboard player (arrows + numpad). The joiner spawns next to the lead (the first rat still standing) with fresh class stats, the party's gold upgrades, a brief invulnerability, and the next slot's colour and glyph. Back on a joined pad, or F6 again, drops that rat out. Later rats move up a slot and take its colour, and with one rat left the run goes back to solo with player 1 keeping everything. Party scaling (`run.players`, then `zoneScaling()`) updates at once, so new spawns, nest children and the next boss follow the party size. Co-op friendly fire stays off. `coopStart` now shares `partyOn`/`addPlayer` with drop-in. Boot check added. |
| 2026-10-12 | **Colour callouts (Taylor approved).** In co-op the announcer names rats by player colour plus class (`CLASSES[k].call`): "Red Rat needs food badly!", "Blue Slinger is about to die!", "Yellow Sneak shot the food!". The line is tinted with that player's colour. Solo play uses the class name. announcer.js is built in three layers. (1) Audio hooks: every line carries a manifest id from Rat 5's sound manifest (`vo_announcer_*`, plus text-only `ann_coop_*` fallbacks). `playVo(id)` plays `vo/<id>.ogg` once `TUNE.announcer.vo.on` is true; it stays off until Taylor picks the voice source. The desktop/Steam build never uses browser speech, and the web build keeps it behind the Voice setting. (2) The visual callout, with its tint. (3) Story id pools per callout kind (low, crit, foodshot, down, revived, token, out). Player shots record who fired them, so "shot the food" names the shooter, at most once every 4 s. Boot check added. |
| 2026-10-12 | **Flow: no walls between levels (Taylor approved).** The exit tally is now a 2.5 s overlay (`TUNE.tally.autoSecs`) with a draining bar. It dismisses itself, and Enter, Space, E or the button skips it. Story scenes never open mid-combat: `tickStory` only opens a queued scene when `calm()` holds, meaning no revealed boss and no awake enemy within 16 units (sleeping packs, patrolling predators, disguised mobs and nests don't count; the first 4 s of a level always count as calm, so intro beats still play). A scene waits for that lull or the next quiet level start, and Esc still skips it. System checks cover both. |
| 2026-10-12 | **Realm hub (Taylor approved).** The Nest has a "Where to?" picker with a City row (every city level this burrow has reached, from `meta.maxDistrict`) and a Sewers row (every sewer level reached, from `meta.maxSewer`). The Sewers row opens after your first manhole. Picking a rat starts at the chosen level (`startRun(k, { realm, idx })`). A sewer-realm run stays underground: a ladder leads to the next sewer level, so sewer progress no longer waits on city loops. The default city run keeps the old surface↔sewer flow. **Continue:** a checkpoint (`meta.cont`: run counters plus player-1 stats) is saved at the start of every level and cleared on death, so Continue resumes the live run at its last level; it's a checkpoint, not a second life. Co-op partners resume with fresh stats. Boot check added. |
| 2026-10-13 | **Phase 4 has lab trials** (`scripts/lab/trials-p4.mjs`): save slots, the Nest shop and its gold income, held flasks, difficulty, co-op, the single-player gamepad, and art readability (no player hues on enemies, rings and glyphs on top, "find yourself" in a 120-mob horde). In co-op trials players 2–4 are simple pad bots that follow, fight, revive and back off when hurt. | The standing rule: every new feature gets a tiered-score trial. The pad bots are weaker than the QA bot (no dodge, specials or vials), so co-op clear speed is reported but not scored. |
| 2026-10-13 | **Lab fights are compared by the median or mean of several, never one, and a flask is judged in a scripted fight.** | The same free bot fight swings 3× either way (who targets whom, crits, turbo), and seeding `Math.random` doesn't help while the render loop runs between steps. The flask trial holds the right stick and stands its ground (Iron Hide: a sneak in a ring of attackers; Splitclaw: a tank against brutes that don't fight back), so the flask is the only difference. Difficulty uses the same scripted fight per mode. Damage taken counts per second survived, so a rat that dies mid-fight (as a 130-HP sneak does on Normal) doesn't cap the number. |
| 2026-10-13 | **The debug god toggle only sets `G.god`.** It used to write `st.taken` (0 on, 1 off), so scripted runs that called `god(false)` played with no Armor until their first level-up. | `hurtP`, the drain and the Reaper already check `G.god`. Probes run before this (balance, insane, classes) measured level 1 without Armor. |
| 2026-10-13 | **The on-screen stick drives player 1 only.** In co-op it used to move every rat (player 2 slid 6.8 units in a second when P1 pushed the stick). | Found by the co-op trial. Players 2–4 have their own pad or keys. |
| 2026-10-12 | **Soundtrack v3 stems ("Sewer Mass", MUSIC_V3.md).** src/audio/stems.js loads the ten v3 Opus files from public/music/v3/ (about 6 MB; masters and `_alt` renders aren't shipped). It starts every loop on one shared clock, so the 8-, 16- and 32-bar loops stay phase-locked. Intensity comes from layer gains, following MUSIC_V3's mapping: bed at 0; combat layer at 0.6 for intensity 1; combat 1 with bed 0.85 for 2. At 3, boss_p1 plays (0.5 before the reveal), p2 joins from phase 2 and p3 at phase 3, and the bed fades out over a bar. The menu plays the menu loop alone. Layer fades are 0.25 s ramps that start exactly on a bar line (2.5 s); boss phase entries snap to the next beat. Stingers play on the next beat while the loops duck: victory on boss death, level clear on the tally, and death. Full boss stacks are trimmed to 0.85. `settings.musicMode` picks 'v3' or 'procedural'. 'v2' isn't in the repo, so it plays procedural. A failed fetch or decode falls back to the old `scheduleMusic()` automatically. Filenames are fixed ids, so Rat 5's re-renders drop in unchanged. CR-9 to CR-15 aren't implemented. Boot check added. |
| 2026-10-13 | **Soundtrack v3 QA fixes (Rat 7: P27-1/2/4/5).** Loaded stems fade out whenever musicMode isn't 'v3' and fade back in on the next bar line. A fade that hasn't started yet is replaced starting from the layer's real level, not its unreached target, so there's no click. Stem loading times out after 20 s and falls back to procedural. It also starts lazily from the music tick, so switching to v3 mid-session loads the stems. Quitting from pause no longer plays the death stinger. |
| 2026-10-13 | **Touch play is off for now** (Taylor's call). The on-screen controls aren't built (`TOUCH_CONTROLS = false` in `src/ui/touch.js`); a touch-only device shows a one-line notice instead. New actions need a key and How to Play text, not a touch button. | Focus on keyboard/mouse and gamepad. The code stays so touch can come back with one flag. |
| 2026-10-13 | **Treasure-room fixes (Rat 7 QA, #24).** Gold piles in the treasure room only land on ground-level tiles (floor height < 0.5). The `treasure-room` seed had been putting loot on unreachable roofs at y=11. The fix is in placement, not a new seed, so any future seed is safe. Treasure drains, hidden in about 35% of levels, now stay sealed and dim until the level's boss is down. A drain is a bonus room after the fight, not a way to skip the boss. |
| 2026-10-13 | **Roof loot: check again after placing a pipe (Rat 7 patch).** `reachRoofLoot` used to assume a newly placed climb pipe reached the loot. When the roof steps up more than a hop past the pipe, the loot stayed stranded. It now checks `onRoof` again and, if the loot is still unreachable, sets it down on the street. |
| 2026-10-13 | **Melee swings no longer pop floor vials (Rat 7 QA, P23-1).** Since #23, the melee `primary` area attack also set off Rot Vials, so melee classes popped the vials that elites, chests and bins drop at their feet. Now only specials and shots pop floor vials, and a freshly dropped vial can't be popped at all for `TUNE.vials.popGrace` (1 s). |
